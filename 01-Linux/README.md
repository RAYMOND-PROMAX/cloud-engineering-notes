# Linux

Linux 系统运维与工程实践知识库。

## 学习目标

围绕 Linux 系统建立从理论到实践的完整认知：

> 理论 → 部署 → 观察 → 排障 → 优化 → 验证 → 总结

重点关注系统中的：

* 网络连接
* 进程与线程
* CPU
* 内存
* 磁盘与 I/O
* 文件描述符
* TCP/IP
* 系统调用
* 服务运行状态
* 日志与可观测性
* 性能与故障排查

## 学习方法

不以记忆命令为目标，而是理解：

**数据从哪里进入 → 经过什么环节 → 在哪里处理 → 哪里可能阻塞 → 如何观察 → 如何定位问题 → 如何优化 → 如何验证。**

## 实践原则

每一个知识点尽可能通过实际环境验证：

1. 理解原理
2. 部署实验
3. 建立基线
4. 制造压力或异常
5. 观察系统状态
6. 提出假设
7. 修改一个变量
8. 再次验证
9. 总结工程经验
