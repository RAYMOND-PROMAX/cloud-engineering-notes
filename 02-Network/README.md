# 第二章：计算机网络与工程实践

> 从网络协议与数据包传输机制出发，理解网络通信原理，探索网络架构、工程实践与故障排查方法。

计算机网络是现代 IT 基础设施的重要组成部分，也是理解 Linux 系统通信、云原生网络、分布式系统及 AI Infrastructure 的基础。

本章围绕计算机网络的基础原理、协议机制、网络设备、通信链路及工程实践展开，重点研究数据如何在不同主机、网络设备与服务之间传输，以及网络异常发生时如何通过协议分析、抓包与系统观测定位问题。

不仅关注网络设备如何配置，更注重理解网络通信背后的运行机制、架构设计与工程应用。

## 学习目标

通过本章的学习与探索，希望能够：

- 理解 OSI 七层模型与 TCP/IP 协议栈的分层思想。
- 掌握以太网、MAC、ARP、IP、ICMP、TCP、UDP 等核心网络协议。
- 理解交换机、路由器、网关、防火墙等网络设备的工作机制。
- 掌握 VLAN、子网划分、静态路由、动态路由与 NAT 等基础技术。
- 理解 DNS、HTTP/HTTPS、TLS 等应用层协议与通信流程。
- 熟悉常见网络诊断工具，能够分析数据包传输过程。
- 建立从网络现象、通信链路到协议机制的系统化故障排查思路。

## 学习与研究方法

坚持从基础原理出发，结合实际网络场景，通过实验观察与数据分析理解网络运行机制。

重点围绕以下问题展开：

1. **数据从哪里来？** 明确通信源端、目标地址及业务需求。
2. **数据经过哪些环节？** 理解协议封装、路由选择、交换转发与网络设备的处理过程。
3. **网络为什么这样工作？** 从协议设计与通信机制解释网络行为。
4. **哪里可能出现异常？** 分析丢包、延迟、连接失败、路由异常及访问控制问题。
5. **如何观察和定位？** 通过抓包、网络指标、设备状态与系统日志寻找证据。
6. **如何验证和改进？** 通过实验、配置调整与结果对比验证问题是否得到解决。

## 文档原则

- **原理优先**：不仅记录配置命令，更关注协议机制和数据传输过程。
- **场景驱动**：从实际通信需求和网络问题出发，理解技术的应用价值。
- **实验验证**：通过抓包、配置实验与故障模拟验证理论知识。
- **系统化分析**：结合网络分层、拓扑关系与通信路径定位问题。
- **持续积累**：随着技术学习和工程实践，逐步完善文章与研究内容。
